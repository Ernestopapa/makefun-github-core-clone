Git Forge: a GitHub-compatible git forge implemented in TypeScript (Node 22).

## Features
- Git Smart-HTTP protocol
- REST API (v3)
- GraphQL API (queries, mutations, pagination, global IDs)
- MCP server (6 tools over JSON-RPC)
- Deterministic in-memory data store

## Run it

```sh
export MAKEFUN_ENV_URL=<env-url> MAKEFUN_SHOP_TOKEN=<token>
node main.ts
```
