# Git Forge

A GitHub-compatible git forge implemented in TypeScript (Node 22).

## Features
- Git Smart-HTTP protocol
- REST API (v3)
- GraphQL API (queries, mutations, pagination, global IDs)
- MCP server (6 tools over JSON-RPC)
- Deterministic in-memory data store

## How to Run
1. Set `MAKEFUN_ENV_URL` and `MAKEFUN_SHOP_TOKEN`.
2. Run `node main.ts`.
